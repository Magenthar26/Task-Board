
✅ Task Management Board

A responsive and interactive task management application that supports **Kanban-style workflow** and **List View**. Features include drag & drop task movement, deadline-based auto-sorting, and modal-based task creation. Tasks persist using `localStorage`.

---

📋 Features Checklist

📝 Task Creation Modal

  * [x] Create tasks with:

  * [x] Task name
  * [x] Description
  * [x] Status (Not Started, Scheduled, In Progress, Completed)
  * [x] Start Date & Deadline
  * [x] Optional Comments
  * [x] Input validation and date range control
  * [x] Modal animation and smooth UI transitions

 📊 Kanban Board View

  * [x] Organized columns by task status
  * [x] Drag & drop support for moving tasks between columns
  * [x] Auto-move overdue tasks to a separate **Pending** column

📄 List View Mode

  * [x] Tasks grouped and displayed by status
  * [x] View, edit, and delete options for each task
  * [x] Status-color-coded sections
  * [x] Scrollable and mobile-optimized
  
⚙️ Task Actions

  * [x] Edit task directly using modal
  * [x] Delete task with one click
  * [x] Expand/collapse task description and comments

 💾 Persistent Storage

  * [x] Stores tasks in browser `localStorage`
  * [x] Prevents duplicate entries using unique IDs
  * [x] Saves current view mode (Kanban/List) between sessions

 📱 Responsive Design

  * [x] Mobile-friendly layout
  * [x] Responsive Kanban and List layouts using Flexbox
  * [x] Scrollable task containers with sticky headers
