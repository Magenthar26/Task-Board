# ✅ Task Management Dashboard

A responsive and interactive **Task Management Dashboard** built with HTML, CSS, and JavaScript. This project demonstrates **drag-and-drop task management**, task creation, editing, deletion, filtering, sorting, and keyboard shortcuts. Tasks are persisted using `localStorage`.


## 📋 Features

### Task Management
- Create tasks with:
  - Name, Description
  - Status (Not Started, Scheduled, In Progress, Completed)
  - Start Date & Deadline
  - Optional Comments
- Edit tasks directly in modal
- Delete tasks with one click
 
### Filtering & Sorting
- Sort tasks by status, date, or priority
- Search functionality to quickly find tasks

### Keyboard Shortcuts
- **Ctrl+N**: Open task creation modal
- **Ctrl+F**: Focus search input
- **Delete**: Remove the last task in the list

### Persistence
- Tasks are stored in browser `localStorage`
- Prevents duplicate entries using unique IDs
- Saves current view mode (Kanban/List) between sessions

### Responsive Design
- Mobile-friendly layouts
- Scrollable task containers with sticky headers
- Smooth UI transitions and animations
